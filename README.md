# proof-legal

Public legal and support pages for the **Proof** iPhone app, served with GitHub Pages at
<https://taxulas.github.io/proof-legal/>.

This repository contains only public documents: the privacy policy, the terms of use and the
support page, in English, French and German. It holds no application source, no credentials and
no user data.

## Structure

Plain static HTML with a single stylesheet. No framework, no build step, no JavaScript, no
analytics and no cookies. English lives at the canonical paths; the other languages hang off them.

```
/                 /privacy/            /terms/            /support/
/fr/              /privacy/fr/         /terms/fr/         /support/fr/
/de/              /privacy/de/         /terms/de/         /support/de/
style.css
```
